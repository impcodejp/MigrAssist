1. 起動と画面構成

1.1 起動方法

インストール後、スタートメニューまたはデスクトップのショートカットから「MigrAssist」を起動する。

2. CSVファイルの取込

手順

ステップ 1：MJSシステムのCSVファイルを指定する

  1. 「参照」ボタンをクリックしてファイル選択ダイアログを開く
  2. MJSシステムから出力したCSVファイルを選択する
  3. ファイルパスがテキストボックスに表示されることを確認する
  4. ファイルの文字コードをドロップダウンで選択する（デフォルト：SJIS）

または、ファイルパスをテキストボックスに直接入力することもできる。

ステップ 2：他社システムのCSVファイルを指定する

ステップ 1 と同様に、他社システムから出力したCSVファイルを指定する。

ステップ 3：「ファイル取込」ボタンをクリックする

  1. 「ファイル取込」ボタンをクリックする
  2. 両ファイルの読み込みが成功すると、突合設定テーブルが表示される

文字コードの選択について

選択肢説明使用例
SJISShift_JIS（デフォルト）多くの給与システムのCSV出力
UTF-8BOMなしUTF-8UTF-8形式のCSV
UTF-8 BOMBOMありUTF-8ExcelからCSV保存したファイル

注意：文字コードが間違っていると文字化けのエラーが発生する。正しい文字コードをシステム担当者に確認すること。

3. 突合設定の調整

ファイル取込後に表示される突合設定テーブルで、MJSシステムと他社システムのどの列同士を突合するかを設定する。

3.1 テーブルの見方

行内容操作
比較対象 チェックボックス。ONにした列が突合される。
先頭列（キー列）は「—」固定で変更不可。 		クリックでON/OFFを切り替える
MJSシステム MJSシステムCSVのヘッダー名（変更不可） 読み取り専用
他社システム 他社システムCSVのどのヘッダーに対応するかを選択する。
MJSのヘッダー名と完全一致する場合は自動で選択される。 		ドロップダウンから選択
許容誤差± この値以内の差異を「一致」とみなす。
空欄または 0 は完全一致のみ「一致」。数値列にのみ有効。 		整数を入力

3.2 先頭列（キー列）について

テーブルの先頭列はMJSシステムCSVの1列目が自動的に「キー列」として使用される。 キー列はMJSと他社のレコードを突合する際の照合キーとなる（例：社員コード）。 キー列の「他社システム」行で、対応する他社システムのキー列を必ず選択すること。

3.3 設定例

以下は「社員コード」をキー列として「欠勤日数」「出勤時間」を突合する例。

行 社員コード（キー列） 欠勤日数 出勤時間 所定内残業
比較対象 — ☑ ☑ □
MJSシステム 社員コード 欠勤日数 出勤時間 所定内残業
他社システム EMP_CODE ▼ ABSENCE_DAYS ▼ WORK_HOURS ▼ （未選択）▼
許容誤差± 0 5 0

この例では：

  • 「欠勤日数」は完全一致チェック
  • 「出勤時間」は ±5 以内の差異は一致とみなす
  • 「所定内残業」は比較対象OFFのためスキップ

4. 設定の保存・読み込み

突合設定は JSON ファイルとして保存・読み込みができる。毎回設定し直す手間を省くために活用する。

4.1 設定を保存する（設定出力）

  1. 突合設定テーブルで設定を完成させる
  2. 「設定出力」ボタンをクリックする
  3. ファイル保存ダイアログが開くので、保存先と名前を指定して保存する（拡張子：.json）

保存される情報：

  • MJSシステム側の各列ヘッダー名
  • 他社システム側の対応列ヘッダー名
  • 比較対象チェックの状態
  • 許容誤差の値

4.2 設定を読み込む（設定取込）

  1. CSVファイルを取込済みの状態にする（ファイル取込が先）
  2. 「設定取込」ボタンをクリックする
  3. ファイル選択ダイアログが開くので、保存済みの設定ファイル（.json）を選択する
  4. 設定が読み込まれ、突合設定テーブルが更新される

注意：設定ファイルのヘッダー名と現在取り込んでいるCSVのヘッダー名が一致しない場合は、エラーメッセージが表示されて設定は適用されない。CSVのヘッダーを確認すること。

5. 突合の実行

実行前チェックリスト

「実行」ボタンをクリックする前に、以下をすべて確認すること。

確認事項確認方法
MJS・他社システムのCSVが取込済みである突合設定テーブルが表示されている
キー列の「他社システム」が選択されている先頭列のプルダウンに値が入っている
比較対象チェックがONの列が1件以上ある比較対象行に☑が入っている列がある
比較対象ONのすべての列で他社システムが選択されている☑が入っている列のプルダウンに値が入っている
出力フォルダが指定されている出力フォルダ欄にパスが入っている

実行手順

  1. 出力フォルダを「参照」ボタンまたは直接入力で指定する
  2. 「実行」ボタンをクリックする
  3. 進捗バーが表示され、処理の進行状況が表示される
  4. 処理が完了すると「突合処理が完了しました。」のダイアログが表示される
  5. 「OK」をクリックして閉じる

実行中の表示

実行中は進捗バーがリアルタイムで更新される。

ステップ表示メッセージ
1/6MJSシステムCSVを読み込み中...
2/6他社システムCSVを読み込み中...
3/6突合処理中...
4/6サマリーファイルを生成中...
5/6明細ファイルを生成中...
6/6完了

6. 出力ファイルの確認

突合処理が完了すると、指定した出力フォルダに以下のファイルが生成される。

ファイル名のタイムスタンプは実行日時（例：2026年6月4日 13:45 → 202606041345）。

6.1 サマリー比較ファイル

ファイル名：サマリー比較_yyyymmddhhmm.csv

各比較列の不一致件数を一覧で確認できるファイル。まずこのファイルを開いて全体像を把握する。

出力例：

項目名,結果
出勤日数,〇
欠勤日数,3
出勤時間,〇
所定内残業,12
残業時間,〇
MJS側のみ存在,2
他社側のみ存在,0
「結果」の値意味
〇全レコードが一致（不一致件数ゼロ）
数値不一致があったレコードの件数

末尾の行の意味：

行意味
MJS側のみ存在MJSにはあるが他社CSVには存在しないレコードの件数
他社側のみ存在他社CSVにはあるがMJSには存在しないレコードの件数

6.2 明細比較ファイル

ファイル名：明細比較_yyyymmddhhmm.csv

不一致があった列ごとに、どのレコードで不一致が発生したかを確認できるファイル。

不一致が一件もない場合は生成されない。

出力例：

項目名：欠勤日数
社員コード,MJS値,他社値,差異
1001,2,0,2
1045,1,3,-2
1089,0,1,-1

項目名：所定内残業
社員コード,MJS値,他社値,差異
1001,20,25,-5
列名内容
社員コード（キー列ヘッダー名）不一致があったレコードのキー値
MJS値MJSシステム側の値
他社値他社システム側の値
差異MJS値 − 他社値（数値列のみ。文字列列は空欄）

片側のみ存在するレコードの表示：

ケースMJS値他社値
MJS側のみ存在MJSの値（空欄）
他社側のみ存在（空欄）他社の値

注意：両ファイルとも UTF-8 BOM 付き形式のため、Excelで直接開くことができる。

7. エラーと対処方法

ファイル取込時のエラー

エラーメッセージ原因対処方法
ファイルパスが未入力です ファイルパスが空のまま取込ボタンを押した MJS・他社システム両方のファイルパスを入力する
ファイル読み込みエラー: ... 指定したパスにファイルが存在しない、またはアクセス権限がない ファイルパスが正しいか確認する。ファイルが別のアプリで開かれている場合は閉じる
指定された文字コード(...)でファイルを読み込めませんでした 文字コードの指定が誤っている ドロップダウンで正しい文字コードを選択して再度取込する
ヘッダー行が空です CSVファイルの1行目が空、またはファイルが空 CSVファイルの内容を確認する

実行時のバリデーションエラー

エラーメッセージ原因対処方法
MJSシステムのCSVファイルが指定されていません MJSシステムCSVが未取込 「ファイル取込」を先に実行する
キー列の他社システム側の列が選択されていません 突合設定テーブルの先頭列（キー列）のプルダウンが未選択 先頭列の「他社システム」行のプルダウンから対応する列を選択する
比較対象の列が1件も選択されていません 比較対象行にチェックが一つもない 突合したい列の「比較対象」チェックボックスをONにする
比較対象列「〇〇」の他社システム側の列が選択されていません 比較対象ONの列に他社システムの列が未設定 該当列の「他社システム」プルダウンから対応する列を選択する
出力フォルダが指定されていません 出力フォルダパスが空 「参照」ボタンまたは直接入力で出力フォルダを指定する

設定取込時のエラー

エラーメッセージ原因対処方法
設定ファイルのヘッダーと取込済みCSVのヘッダーが一致しないため、設定を適用できません。 保存した設定ファイルのMJSヘッダー名と、現在取り込んでいるCSVのヘッダー名が異なる。 エラーメッセージ内に差分（設定ファイルにのみ存在／CSVにのみ存在）が表示される。 現在取り込んでいるCSVに合った設定ファイルを選択する。 または、CSVファイルを正しいものに差し替えて再取込する。

突合処理中のエラー

エラーメッセージ原因対処方法
他社システムCSVにキー列「〇〇」が見つかりません 設定のキー列名が他社CSVのヘッダーと一致しない ファイル取込をやり直して突合設定テーブルを再設定する
ファイル書き込みエラー: ... 出力フォルダへの書き込み権限がない、またはディスク容量が不足 出力フォルダのアクセス権限とディスク空き容量を確認する

エラーの閉じ方

エラーメッセージが画面下部に表示されたら、「閉じる」ボタンをクリックして消す。

付録：基本操作フロー

通常の使用手順のまとめ。

  1. MigrAssist を起動する
  2. MJSシステムのCSVファイルを指定する（文字コードを確認）
  3. 他社システムのCSVファイルを指定する（文字コードを確認）
  4. 「ファイル取込」ボタンをクリックする
  5. 突合設定テーブルで以下を確認・設定する：
    • キー列の「他社システム」プルダウンを選択する
    • 突合したい列の「比較対象」チェックをONにする
    • 各列の「他社システム」プルダウンを選択する
    • 必要に応じて「許容誤差±」を入力する
  6. 設定を保存する場合は「設定出力」をクリックする
  7. 出力フォルダを指定する
  8. 「実行」ボタンをクリックする
  9. 完了ダイアログを確認し「OK」をクリックする
  10. 出力フォルダの「サマリー比較_*.csv」「明細比較_*.csv」を確認する
